# SWYNEX Responsive Landing Page

A responsive landing page built with HTML, CSS, and JavaScript for a project-based internship task.

## Features
- Responsive layout for desktop, tablet, and mobile
- Navigation links with a mobile menu
- Hero section, services, about section, testimonial, contact section, and footer
- Smooth scrolling and current year in footer
- Accessible labels and reduced-motion support

## Run locally
Open `index.html` in a web browser. No build tools are required.

## Customize before submitting
- Replace the sample brand name, testimonial, and email with your own project details if desired.
- Take screenshots at desktop and mobile widths.
- Test every navigation link and the mobile menu.

## Technologies
HTML5, CSS3, JavaScript
